# NVIDIA Jetson 与 Dock 图像识别笔记

## 1. 图像请求

### OpenAI 兼容接口：PNG Base64

将 `dock.png` 编码后以内嵌 `data:image/png;base64,...` 的形式发送。PNG 图片的 MIME 类型为 `image/png`。

```bash
IMAGE_BASE64=$(base64 -w 0 dock.png)

cat > request.json <<EOF
{
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "Look at the dock area in this image. Is there any vehicle (car, truck, or van) present? Answer only 'yes' or 'no'."
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "data:image/png;base64,${IMAGE_BASE64}"
          }
        }
      ]
    }
  ],
  "max_tokens": 2,
  "temperature": 0.1,
  "chat_template_kwargs": {
    "enable_thinking": false
  }
}
EOF
```

### Ollama：月台占用判断

将 `IMG_PATH` 改为待判断图片的路径。Ollama 的 `images` 字段使用纯 Base64，不需要添加 `data:image/png;base64,` 前缀。

```bash
IMG_PATH="1.jpg"
IMAGE_BASE64=$(base64 -w 0 "$IMG_PATH")

cat > request2.json <<EOF
{
  "model": "qwen3.5:2b",
  "stream": false,
  "think": false,
  "keep_alive": -1,
  "messages": [
    {
      "role": "system",
      "content": "You are a dock inspector. Check if THIS dock bay is occupied by a truck/trailer. A docked truck shows ONLY its rear face tight against the dock opening. You will NEVER see tires, wheels, or the vehicle's side when properly docked. Rain flaps or rain guards attached to the rear are part of the truck, ignore them. Lighting varies (day/night); inside the trailer may be lit while outside is dark, that is normal and still counts as docked. === HARD NO (answer 'no' immediately) === 1. Any vehicle SIDE wall or curtain, or tires near left/right edges of the image. 2. No vehicle rear face at the opening (empty dock, or only outdoor view). 3. Dock door covers >50% of the opening. === YES CONDITIONS (all must be true) === 1. A vehicle rear face fills the dock opening: either closed doors with panels/hinges/tape, or open doors showing a dark interior (may be lit inside), or rear with rain flaps/guards. 2. No gap with outdoor light between rear face and dock edge. In darkness, the area directly outside the dock will be uniformly dark if a truck is present, but an empty dock may show distant lights or faint background. Focus on the presence of the rear face, not ambient brightness. 3. The rear face is aligned with the opening, not off-center. Ignore people, pallets, forklifts. Answer exactly one word: 'yes' or 'no'."
    },
    {
      "role": "user",
      "content": "Is a truck/trailer directly docked at this dock? Look for a rear face against the opening (closed doors, open dark interior, or rain flaps). Ignore side views, off-center tires, and lighting differences. Answer 'yes' or 'no'.",
      "images": ["${IMAGE_BASE64}"]
    }
  ],
  "options": {
    "temperature": 0,
    "num_predict": 1,
    "num_ctx": 3072,
    "mirostat": 0
  }
}
EOF
```

通过 Ollama Chat API 发送请求：

```bash
curl http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
  -d @request2.json
```

## 2. 文本请求

通过 OpenAI 兼容的 Chat Completions API 发送纯文本请求：

```bash
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemma4",
    "messages": [
      {"role": "user", "content": "Is 1+1=2? Answer only yes."}
    ],
    "max_tokens": 2
  }'
```

## 3. Ollama 模型预热

发送一次简单请求以加载模型，并设置 `keep_alive` 为 `-1`，让模型持续驻留：

```bash
curl http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.5:2b",
    "stream": false,
    "think": false,
    "keep_alive": -1,
    "messages": [
      {"role": "user", "content": "ping"}
    ]
  }'
```

## 4. Ollama 图像请求

下面的写法生成适用于 `/api/generate` 或 `/api/chat` 的请求体。`/api/chat` 使用 `messages`；若调用 `/api/generate`，需按该接口改用 `prompt` 和 `images` 字段。

```bash
IMAGE_BASE64=$(base64 -w 0 dock.png)

cat > request.json <<EOF
{
  "model": "qwen3.5:2b",
  "stream": false,
  "think": false,
  "keep_alive": -1,
  "messages": [
    {
      "role": "user",
      "content": "月台是否有车辆？只回答是或否。",
      "images": ["${IMAGE_BASE64}"]
    }
  ]
}
EOF

curl http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
  -d @request.json
```

## 5. Jetson 性能与系统管理

### 功耗模式与时钟

```bash
# 设置功耗模式；模式编号及对应功率取决于 Jetson 型号和配置
sudo nvpmodel -m 1

# 锁定当前模式下的时钟
sudo jetson_clocks

# 查看当前功耗模式
sudo nvpmodel -q

# 查看实时系统与 NVIDIA 硬件状态
sudo tegrastats
```

原始记录将 `nvpmodel -m 1` 分别标为 15W 和 25W，存在不一致；请以设备型号支持的模式及 `nvpmodel -q` 输出为准。

### 清理 Linux 文件缓存

```bash
sudo sysctl -w vm.drop_caches=3
```

此命令清理 Linux 的頁面缓存、目录项和 inode 缓存，不等同于卸载或清除 Ollama 模型。仅在需要时使用。

### Wi-Fi 连接

```bash
nmcli device wifi connect "<SSID>" password "<PASSWORD>"
```

将 `<SSID>` 和 `<PASSWORD>` 替换为本地网络信息；不要把真实密码提交到代码仓库或共享笔记中。

### 设置默认启动目标

```bash
# 默认启动到图形界面
sudo systemctl set-default graphical.target

# 立即切换到图形界面
sudo systemctl start graphical.target

# 默认启动到命令行界面
sudo systemctl set-default multi-user.target

# 当前会话立即切换到命令行界面
sudo systemctl isolate multi-user.target

# 查看当前默认启动目标
systemctl get-default
```

### 查看 Dock 服务日志

```bash
sudo journalctl -u dock_occupancy.service -f
```
