## Ultralytics YOLO 是一系列实时计算机视觉模型
### YOLO 分类任务
| 任务类型 | 核心含义 | 输出结果 | 简单示例 | 是否适合当前 Dock 占用判断 |
|---|---|---|---|---|
| **目标检测** Object Detection | 判断图中有什么物体，并确定物体位置 | 类别、置信度、普通矩形框 | 检测到货车，并框出货车位置 | **可以，但偏复杂**。需要通过“检测到车辆 = 有车”进行判断 |
| **实例分割** Instance Segmentation | 精确分割每个独立物体，并区分同类个体 | 每个物体单独的像素轮廓 | 分别标出三辆车的不同轮廓 | **不推荐**。Dock 占用判断通常不需要精确车辆轮廓 |
| **语义分割** Semantic Segmentation | 判断图像中每个像素属于什么类别，但通常不区分同类个体 | 每个像素的类别标签 | 把车辆、地面、墙壁分别标记出来 | **不推荐**。除非需要精确判断车辆占用了 Dock 的哪些区域 |
| **深度估计** Depth Estimation | 估算画面中各位置与摄像头之间的距离 | 每个像素的深度或距离 | 判断车辆距离 Dock 还有多少米 | **不适合单独判断占用**，更适合测距或判断车辆是否停靠到位 |
| **分类** Classification | 判断整张图片属于哪个类别，不标记物体位置 | 图片类别及概率 | 输出 `occupied 0.98` 或 `empty 0.97` | **最适合**。单个 Dock 已经裁剪，只需判断有车或无车 |
| **姿态估计** Pose Estimation | 检测人体或物体的关键点，判断姿态和动作 | 关键点坐标及连接关系 | 检测头部、肩部、手肘和膝盖 | **不适合**。主要用于人体动作、安全行为等场景 |
| **有向边界框** Oriented Bounding Box（OBB） | 使用可旋转矩形框定位倾斜目标 | 类别、置信度、旋转框和角度 | 检测航拍画面中倾斜停放的车辆 | **通常不需要**。除非摄像头俯拍且车辆方向变化明显 |
| **跟踪** Tracking | 在连续视频中持续识别同一个目标，并分配固定 ID | 目标位置、类别、轨迹和 ID | 跟踪同一辆车进入、停靠和离开 Dock | **可作为扩展功能**。适合记录车辆进出过程和停留时间 |

### 一句话区分

- **分类**：整张图是什么？
- **目标检测**：有什么，在哪里？
- **实例分割**：每个独立物体的精确轮廓是什么？
- **语义分割**：每个像素属于什么类别？
- **深度估计**：每个位置距离摄像头多远？
- **姿态估计**：目标的关键点和姿态是什么？
- **有向边界框**：倾斜物体在哪里、朝什么方向？
- **跟踪**：视频中的目标是不是之前出现的同一个目标？

### 训练步骤
* 1.train       训练
* 2.test        测试
* 3.validation  验证

#### 1.分类训练
```shell
# 在 YOLO 的分类任务中，data 参数不需要 .yaml 配置文件，而是直接指向数据集的根目录。
# YOLO 会自动根据目录结构（即您提供的 train/empty, train/occupied 等）来识别类别。
# 分类模型训练（使用CPU训练）
yolo classify train \
    model=yolo11s-cls.pt \
    data=/home/jeffzhou/apps/dock_cls_project_yolo11s/dock_cls_dataset \
    epochs=100 \
    imgsz=384 \
    batch=16 \
    workers=4 \
    device=cpu \
    project=./runs/classify \
    name=dock_cpu_v1 \
    patience=10 \
    optimizer=AdamW \
    lr0=0.001


# 分类模型训练（使用GPU训练）- 离线训练建议的指令
# 针对现在“有 GPU、但没有网络”的情况，建议用下面这条离线训练命令：
yolo classify train \
  model=/home/jeffzhou/apps/dock_yolo11s_train/yolo11s-cls.pt \
  data=/home/jeffzhou/apps/dock_yolo11s_train/dock_cls_dataset \
  epochs=100 \
  imgsz=384 \
  batch=32 \
  workers=6 \
  device=0 \
  project=./ \
  name=dock_gpu_v0729 \
  patience=30 \
  optimizer=AdamW \
  lr0=0.001 \
  amp=False

# 如果你想让它更“稳妥”一点，尤其是离线环境，建议再加上：cache=False
yolo classify train \
  model=/home/jeffzhou/apps/dock_yolo11s_train/yolo11s-cls.pt \
  data=/home/jeffzhou/apps/dock_yolo11s_train/train0730/dock_cls_dataset \
  epochs=100 \
  imgsz=384 \
  batch=32 \
  workers=6 \
  device=0 \
  project=./ \
  name=dock_gpu_v0730 \
  patience=30 \
  optimizer=AdamW \
  lr0=0.001 \
  amp=False \
  cache=False

# 参数详解：
#         model=yolo11s-cls.pt: 指定使用 YOLO11s 分类模型。如果本地没有，它会自动下载。
#         data=dock_cls.yaml: 指向刚才创建的数据集配置文件。
#         epochs=100: 训练轮数。
#         imgsz=640: 输入图片尺寸（分类任务通常 224 或 640 均可，月台场景建议 640 以保留细节）。
#         batch=16: 批次大小。根据您的显存调整（AGX Orin 可以尝试 32 或 64，普通显卡 16 较稳）。
#         workers=8: 数据加载线程数。
#         patience=10: 早停机制，如果验证集指标 10 个 epoch 没提升则停止。
#         optimizer=AdamW: 优化器，分类任务常用。
#         lr0=0.001: 初始学习率。
#         project=./runs/classify: 训练结果保存路径。
#         name=dock_v1: 训练结果保存的文件夹名称。
#         device=0: 使用 GPU 训练。
#         amp=False: 是否使用自动混合精度训练。（false就不会连接网络进行AMP兼容性检查，适合无网训练）

# 分类模型测试
yolo classify predict model=./runs/classify/dock_v1/weights/best.pt source=path/to/your/image.jpg
```
