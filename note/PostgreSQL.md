## psql执行语句

### 快捷命令

| 命令             | 描述           | 示例               |
|----------------|--------------|------------------|
| `\l`           | 列出所有数据库      | `\l`             |
| `\c dbname`    | 切换到指定数据库     | `\c machineData` |
| `\dn`          | 列出当前数据库的所有模式 | `\dn`            |
| `\dt`          | 列出当前模式的所有表   | `\dt`            |
| `\dt schema.*` | 列出指定模式的所有表   | `\dt public.*`   |
| `\d table`     | 查看表结构        | `\d newtable`    |
| `\du`          | 列出所有角色/用户    | `\du`            |
| `\conninfo`    | 显示当前连接信息     | `\conninfo`      |
