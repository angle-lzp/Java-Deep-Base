# Vim 常用快捷方式与显示行号方法

## 一、模式切换

| 快捷键 | 作用 |
|--------|------|
| `Esc` | 返回普通模式（无论当前在什么模式） |
| `i` | 在光标前进入**插入模式** |
| `I` | 在行首进入插入模式 |
| `a` | 在光标后进入插入模式 |
| `A` | 在行尾进入插入模式 |
| `o` | 下方另起一行进入插入模式 |
| `O` | 上方另起一行进入插入模式 |
| `v` | 进入**可视模式**（按字符选择） |
| `V` | 进入**可视行模式** |
| `Ctrl` + `v` | 进入**可视块模式** |
| `:` | 进入**命令模式** |

## 二、光标移动（普通模式）

| 快捷键 | 作用 |
|--------|------|
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右 |
| `w` | 跳至下一个单词开头 |
| `b` | 跳至当前/上一个单词开头 |
| `e` | 跳至单词末尾 |
| `0` | 跳至行首 |
| `^` | 跳至行首第一个非空字符 |
| `$` | 跳至行尾 |
| `gg` | 跳至文件开头 |
| `G` | 跳至文件末尾 |
| `:{n}` + Enter | 跳至第 n 行（如 `:10`） |
| `Ctrl` + `f` | 向下翻页（forward） |
| `Ctrl` + `b` | 向上翻页（backward） |
| `Ctrl` + `d` | 向下翻半页 |
| `Ctrl` + `u` | 向上翻半页 |
| `%` | 跳转到匹配的括号 `() {} []` |

## 三、编辑操作（普通模式）

| 快捷键 | 作用 |
|--------|------|
| `x` | 删除光标所在字符 |
| `X` | 删除光标前一个字符 |
| `dd` | 删除当前行 |
| `dw` | 删除光标到单词末尾 |
| `d$` 或 `D` | 删除光标到行尾 |
| `d0` | 删除光标到行首 |
| `yy` | 复制当前行 |
| `yw` | 复制光标到单词末尾 |
| `y$` | 复制光标到行尾 |
| `p` | 在光标后粘贴 |
| `P` | 在光标前粘贴 |
| `u` | 撤销 |
| `Ctrl` + `r` | 重做（恢复撤销） |
| `.` | 重复上一次操作 |

## 四、可视模式操作

| 快捷键 | 作用 |
|--------|------|
| `v` + 移动键 | 选中文本 |
| `d` 或 `x` | 删除选中内容 |
| `y` | 复制选中内容 |
| `p` | 替换选中内容为剪贴板内容 |
| `U` | 将选中字母转为大写 |
| `u` | 转小写 |
| `>` | 向右缩进 |
| `<` | 向左缩进 |

## 五、查找与替换

| 快捷键 | 作用 |
|--------|------|
| `/pattern` | 向下查找 pattern |
| `?pattern` | 向上查找 pattern |
| `n` | 跳至下一个匹配 |
| `N` | 跳至上一个匹配 |
| `:s/old/new` | 替换当前行第一个 old 为 new |
| `:s/old/new/g` | 替换当前行所有 old 为 new |
| `:%s/old/new/g` | 替换全文件所有 old 为 new |
| `:%s/old/new/gc` | 替换时逐个确认 |

## 六、文件与窗口

| 快捷键 | 作用 |
|--------|------|
| `:w` | 保存文件 |
| `:q` | 退出 |
| `:wq` 或 `ZZ` | 保存并退出 |
| `:q!` | 强制退出不保存 |
| `:e filename` | 打开另一个文件 |
| `:split` 或 `:sp` | 水平分屏 |
| `:vsplit` 或 `:vs` | 垂直分屏 |
| `Ctrl` + `w` + `h/j/k/l` | 在分屏之间切换 |
| `Ctrl` + `w` + `q` | 关闭当前分屏 |

## 七、常用进阶技巧

| 快捷键 | 作用 |
|--------|------|
| `ci"` | 改变双引号内的内容（c = change, i = in） |
| `di(` | 删除括号内的内容 |
| `yip` | 复制整个段落（p = paragraph） |
| `>>` | 当前行向右缩进 |
| `<<` | 当前行向左缩进 |
| `==` | 自动缩进当前行 |
| `gg=G` | 全文自动格式化缩进 |
| `Ctrl` + `g` | 显示当前文件信息（行数、百分比等） |

## 八、显示行号方法

### 1. 临时显示行号（当前会话）
在命令模式下执行：
```vim
:set number       " 显示绝对行号
:set nu           " 简写
:set nonumber     " 关闭行号
:set nonu         " 简写
