## Ollama常用指令

### 1.指令
| 命令 | 作用 |
|---|---|
| `ollama serve` | 启动服务（默认监听 `127.0.0.1:11434`）。Windows/macOS 装完通常已在后台运行，不用手动敲 |
| `ollama run <模型>` | 拉取并进入对话交互模式，退出输入 `/bye` 或 `Ctrl+D` |
| `ollama run <模型> "一句话问题"` | 不进入交互，直接单次问答输出（适合脚本） |
| `ollama pull <模型>` | 下载模型（如 `qwen3:8b`、`llama3.1`） |
| `ollama pull <模型>:<标签>` | 指定量化版本，如 `qwen3:4b-instruct-q4_K_M` |
| `ollama list` / `ollama ls` | 列出本地已有模型 |
| `ollama rm <模型>` | 删除本地模型（释放磁盘） |
| `ollama cp <源> <目标>` | 复制/重命名模型，常用于给自定义模型打 tag |
| `ollama show <模型>` | 查看模型详情（参数、模板、系统提示、Modelfile 内容） |
| `ollama show --modelfile <模型>` | 只看可复现的 Modelfile |
| `ollama ps` | 看当前哪些模型还驻留在显存/内存里 |
| `ollama stop <模型>` | 把驻留的模型从显存 unload 掉 |
| `ollama logs` | 看服务日志（排查加载失败、GPU 分配问题） |

### 2.Ollama日志

> Ollama 没有“按模型分的日志文件”
它的日志是服务级的（server 进程输出），模型加载、卸载、推理速度、报错全都打在这里。想看日志，本质是看 

| 指令 | 作用 |
|---|---|
| `sudo journalctl -u ollama -f` | 实时日志 |
| `sudo journalctl -u ollama -n 200` | 只看最近 200 行 |
| `sudo journalctl -u ollama -e` | 直接跳到末尾 |
| `sudo journalctl -u ollama --no-pager` | 不分页，适合管道/重定向 |
| `sudo journalctl -u ollama --since "10 min ago"` | 只看最近 10 分钟 |
| `sudo journalctl -u ollama -o json \| jq .MESSAGE` | JSON 格式，方便 grep/分析 |
| `sudo journalctl -u ollama > ollama.log` | 导出到文件 |
| `sudo systemctl status ollama` | 只看最近几条 + 服务状态（排查是否挂了） |
